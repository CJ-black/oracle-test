# Security Policy

## Supported branch

The `main` branch is the supported branch for security fixes.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting or a private contact channel available to the repository owner. Include enough detail to reproduce the issue, but do not include credentials, private keys, API-key files, or complete secret values.

If a credential may have been exposed:

1. Stop using it immediately.
2. Revoke or rotate it in the relevant provider.
3. Check repository history and deployment logs for additional exposure.
4. Report the incident privately with the affected credential type and approximate time, not the secret itself.

Security reports are handled privately. Please allow time for validation and remediation before public disclosure.
